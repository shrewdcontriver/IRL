# IRL — Your people, not your feed.

**Interactive demo / concept prototype** for a focus-first Instagram experience on Android.

## What is IRL?

IRL is a proposed Android app that lets you keep the useful parts of Instagram while removing the addictive ones:

- **Home screen** → Only Stories (no posts / feed)
- **Reels tab** → Completely blocked
- **DMs & calls** → Fully usable
- **Shared Reels** → You can watch the one your friend sent, but you cannot scroll further into the infinite Reels feed
- **Profiles** → Friends’ posts remain visible

Users stay logged into the official Instagram app. IRL would run as an overlay using Android’s Accessibility Service — no Instagram password is ever required.

## This repository

This is a **simulated interactive demo** created for presentation purposes (NEC / school entrepreneurship challenge).

It is **not** a real Instagram client and does not connect to Instagram.

## How to view the demo

Open `index.html` in any modern browser, or enable GitHub Pages to view it live.

## Project vision

The long-term goal is a lightweight Android app that uses Accessibility Service to enforce these rules on top of the official Instagram application, giving Indian Android users a safer, password-free alternative to existing focus tools.
